# EduVision — веб-прототип для GitHub Pages

Статическая версия: `index.html` в корне, без сервера и сборки. Данные — только демо (коды учеников, без ФИО и школ), хранятся в браузере.

## Как открыть

- Локально: в корне репозитория выполнить `python -m http.server 8132` и открыть <http://127.0.0.1:8132/>.
- Онлайн: <https://sirius-leto-2026.github.io/eduvision/>.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | интерфейс: вкладки «Ученики», «Работы», «Кабинет педагога», «Родителю», «Опыт», «Данные» |
| `app.js` | вкладки, таблица учеников, формы, локальное сохранение, фильтр/сортировка/CSV |
| `analyzer.js` | правила проверки текста, шкалы 1–5, черновик отчёта, сверка фактов, расчёт совпадений с оценками педагога |
| `data.js` | демонстрационные данные: библиотека знаний (6 уроков) и три обезличенных профиля |
| `styles.css` | оформление, карточная раскладка таблиц на телефоне |
| `privacy.html`, `terms.html` | политика конфиденциальности и условия использования |
| `cover.png`, `favicon.png` | обложка для OpenGraph и иконка вкладки |

## Возможности прототипа

- **Ученики.** Добавление по коду (Enter в поле кода тоже отправляет форму), удаление с подтверждением, оценки педагога по говорению, работе в команде и презентации, проекты через `;`.
- **Фильтр и сортировка.** Отбор по группе, сортировка по коду, уровню (A1 → B1) или числу работ.
- **Экспорт таблицы в CSV.** Кнопка «Экспорт таблицы в CSV» выгружает видимые строки в текущем порядке: `Код,Группа,Уровень,Работ,Говорение,Работа в команде,Презентация,Проекты` (UTF-8 с BOM, разделитель — запятая).
- **Работы.** Письменная работа проверяется по правилам курса (грамматика, орфография, лексика и конструкции урока), тест считает процент верных ответов. Фото распознаётся в браузере через Tesseract.js, который загружается с `cdn.jsdelivr.net` только по кнопке «Распознать текст».
- **Кабинет педагога.** Анализ по направлениям с основанием для каждого балла, черновик отчёта, сверка фактов (нельзя утвердить текст с числами и датами, которых нет в данных) и передача отчёта родителю после утверждения.
- **Родителю.** Виден только утверждённый педагогом отчёт.
- **Опыт «система против педагогов».** Экспорт оценок системы, загрузка CSV педагога (`student,direction,score`) и расчёт доли совпадений в пределах ±1 балла.
- **Данные.** Экспорт и импорт JSON, возврат демо-данных, полное удаление данных из браузера.

## Хранение и приватность

- Состояние хранится в `localStorage` под ключом `eduvision-v1`; на сервер ничего не отправляется, cookie и аналитики нет.
- Ученики обозначаются кодами (например, `S-014`), ФИО не вводятся.
- Реальные данные вносятся только при письменном согласии родителей; педагог подтверждает это галочкой при добавлении ученика и каждой работы.
- Удаление ученика удаляет и его работы, и отчёт из `localStorage`.
