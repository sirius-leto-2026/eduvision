Цифровые профили

Ученики хранятся только по коду, без ФИО. Говорение и мягкие навыки — интерпретационные направления: их оценивает педагог.

Загрузка работ

Реальные работы загружаются только с письменного согласия родителей. Фото распознаётся в браузере и никуда не отправляется.

Отчёт для родителей

Опыт «система против педагогов»

  1. Скачайте оценки системы по всем ученикам.
  2. Педагоги независимо ставят свои баллы в таком же CSV: student,direction,score (направления: listening, reading, writing, speaking, grammar, spelling, teamwork, presentation).
  3. Загрузите CSV педагога — система посчитает долю совпадений в пределах ±1 балла.

Данные и конфиденциальность

  • Все данные хранятся только в этом браузере (localStorage); cookie и аналитика не используются.
  • Ученики обозначены кодами, ФИО не вводятся. Реальные работы — только с согласия родителей.
  • Сторонний код: Tesseract.js (лицензия Apache 2.0) загружается с cdn.jsdelivr.net только при нажатии «Распознать текст».
  • Итоговую оценку и текст отчёта утверждает педагог; без утверждения родитель отчёт не видит.
